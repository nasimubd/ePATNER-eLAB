# Changelog

All notable changes to PulseForge are documented in this file.

## 0.1.0 — 2026-08-24

Initial public release of PulseForge, an open-source healthcare operations platform for hospitals, clinics, diagnostic centres, and care facilities.

### Included

* Patient, doctor, appointment, waiting-list, and laboratory-report workflows.
* Medical invoicing, ledgers, transactions, payments, ward services, and operating-theatre bookings.
* Role-based administration, subscription workflows, documentation, security guidance, and Conventional Commit contribution rules.
